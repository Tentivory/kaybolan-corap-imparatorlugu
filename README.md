# Kaybolan Çorap İmparatorluğu 🧾👑

## Bu Nedir? (Ciddiye Alınacak Bir Şey Değil Ama Ciddiye Alınmalı)

Evinizde kaybolan her çorap, aslında gizli bir imparatorluğun vatandaşıdır. Bu repository, o imparatorluğu keşfetmek, anlamak ve (imkansız olsa da) çorapları kurtarmak için tasarlanmış dünyanın en ileri (ve en saçma) bilimsel operasyonudur.

### Özellikler
- Gerçek çalışan Python kodu ile çorap arama simülasyonu
- Rastgele lokasyonlar ve başarı oranları (doğa kanunları gereği düşük)
- Abartılı bilimsel dil ile tamamen absürt yaklaşım
- Gizli mesajlar (saklı, bulmaya çalışma)

## Nasıl Kullanılır?

```bash
python corap_kurtarma.py
```

Sayı girin, operasyon başlasın. Çoraplarınızın dönmesi garanti değil, ama eğlence garanti.

## Bilimsel Temel (Uydurma)

Araştırmalar (hiç yapılmadı) gösteriyor ki çoraplar, çamaşır makinesinin kuantum alanında kayboluyor. Bu kod, o alanı simüle eder. Sonuçlar değişkenlik gösterir çünkü evren rastgeledir.

## Katkıda Bulunma

Pull request gönderin ama çoraplarınızı beraberinde getirmeyin. Onlar özgür olmak ister.
